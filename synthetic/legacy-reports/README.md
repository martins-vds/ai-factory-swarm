# Circulation reports

The Lending Library's monthly circulation reports ran on a reporting server (Crystal-era report
definitions over a nightly copy of the loans database). The server was retired in 2019 and its report
definitions were not kept. What remains is the specification the librarians wrote for it and a few
reports it produced, saved by the branch office.

- `docs/monthly-circulation.md`: what the monthly report shows and how each figure is counted.
- `docs/overdue-notices.md`: the overdue notice batch that ran alongside it.
- `samples/`: reports and notices the old server produced.

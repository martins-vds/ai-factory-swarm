# The folded Migrator, measured (2026-11-19)

ADR-0045 folded the Verifier into the Migrator: the Migrator now verifies its own work, and no Verifier
follows it. This run measures the folded `afs-migrator` (harness `ca620b9`) on the eight phase-4a Migrator
cases, twice each. The baseline is round 2's configuration B (`2026-11-18-4rb`), the variant the fold was
built from.

## A harness bug in the first run
The first runs (`4f-r1`, `4f-r2`, plus `4f-r3` for DM-05F) showed pilot Gates running 76 minutes or being
cancelled at the 90-minute timeout. The cause wasn't the agent:
- **The bug:** the pilot profile's `gates.mutation_changed` hardcoded `--changed-since origin/main`. That
  overrode the `AFS_BASE` CI sets to the PR's base.
- **In the eval repo:** its `main` is unrelated history, so mutation ran on the whole codebase.
  - 4f-r3's test-only DM-05F change failed on surviving mutants in modules it never touched.
  - 4f's BK-05F-fresh Gates timed out.
- **On a live target:** the same flag makes a stacked PR mutate its parent's code.

Harness #211 fixes it:
- `validate.py` rejects the hardcoded base.
- The template and every eval case drop the flag.
- Earlier journal entries stay trusted.

The three pilot cases were run again with the fix (`4h-r1`, `4h-r2`).

**ADR-0045 holds:** the folded Migrator is no worse than the variant it was built from.
